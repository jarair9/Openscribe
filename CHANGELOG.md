# Changelog

All notable changes to Openscribe are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
aims to follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Blob-URL audio playback engine for reliable voice and music audio.
- Voice recorder with live input meter, discard, and a silent-recording guard.
- Per-track audio settings in the Inspector (volume, start, fades, trimming).
- Global mute shared between the title bar and full-screen preview.
- Scribble-style fill animations for shapes and images.
- "None" entrance animation option.

## [0.1.0]

### Added
- Initial public source release: canvas, SVG drawing animations, animated
  hand and pen, text and shapes, scenes with virtual cameras, timelines,
  transitions, audio editing, FFmpeg-powered video/GIF export, local asset
  library, autosave and crash recovery.
